# GLOBAL FUNN Agent Operating System

## Purpose
A small, accountable AI-assisted studio for three pilot channels and related digital products. Agent files are reusable role instructions; they do not run by themselves or grant access to Canva, YouTube, Metricool, payment systems or local software.

## Agent roster

| Workstream | Agent | Main output |
|---|---|---|
| Coordination | Studio Orchestrator | Task plan, handoffs, approval gates |
| Topic discovery | Trend Researcher | Ranked topic slate and evidence |
| News verification | News Researcher | Source-backed fact pack |
| Writing | Hindi Scriptwriter | Spoken Hindi script |
| Video | Shorts Producer | Storyboard, edit and subtitle plan |
| Visual identity | Visual Brand Director | Graphic and thumbnail brief |
| Search packaging | YouTube SEO Strategist | Titles, descriptions and topic cluster |
| Release gate | Fact-check & Compliance Editor | Claim ledger and pass/revise/hold |
| Publishing | Publishing Editor | Book/newsletter/workbook package |
| Product | SaaS Product Architect | Validated problem, PRD and MVP plan |
| Sales | Digital Commerce Growth | Offer, funnel and experiments |
| Repurposing | Content Repurposing Producer | Cross-format content plan |
| Measurement | Analytics & Insights | Performance diagnosis and experiments |
| Channel growth | YouTube Growth Editor | Packaging and channel-level recommendations |

## Standard workflow

1. **Discover:** Trend Researcher + News Researcher establish audience need and evidence.
2. **Plan:** Orchestrator creates tasks, owners, deadlines and acceptance criteria.
3. **Create:** Scriptwriter drafts; Shorts Producer and Visual Brand Director prepare production assets.
4. **Package:** SEO Strategist prepares metadata; Repurposing Producer maps derivatives.
5. **Audit:** Fact-check & Compliance Editor independently checks claims, rights and policy risks.
6. **Approve:** Human owner reviews script, final video, title, thumbnail, description and visibility.
7. **Publish:** Publishing operator executes only after explicit approval and records the live URL.
8. **Learn:** Analytics agent reviews actual data and assigns a small number of experiments.

## Release checklist

- [ ] Every material claim has a traceable source.
- [ ] The video matches title, thumbnail and description.
- [ ] Music, footage, images and fonts have documented usage rights.
- [ ] Synthetic visuals cannot be mistaken for real event footage, or are appropriately disclosed.
- [ ] Personal data and account secrets are excluded.
- [ ] Human owner approves the final export and publication settings.
- [ ] Live URL or platform confirmation is recorded after publication.

## Pilot focus
Start with GLOBAL FUNN, AI Seekho Hindi and Career Compass Hindi. Keep the remaining proposed channels as a backlog until the pilots show repeatable audience demand and manageable production cost.

## Evidence and honesty
Use only metrics actually retrieved from connected platforms or supplied by the owner. Label estimates and hypotheses. Never claim an agent ran, a tool was installed, a video was uploaded, a product was launched or revenue was earned without verifiable evidence.

## Upstream inspiration
The role-based approach is informed by the open-source [Agency Agents](https://github.com/msitarzewski/agency-agents) catalogue. These project-specific agent prompts are tailored workflows, not a wholesale import of the upstream repository.
