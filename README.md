# GLOBAL FUNN LIVE NEWS

**India • World • Beyond** — *Khabar Har Pal, Nazar Global.*

A source-led newsroom dashboard built with Next.js, React, TypeScript, Tailwind CSS and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Editorial safety rules

- No fabricated stories, quotes, sources or evidence.
- Never label a story verified without accessible source references.
- Cross-check significant or disputed claims with independent credible sources where available.
- Distinguish confirmed facts, allegations, opinion, analysis and developing reports.
- Label AI-generated visuals as **AI ILLUSTRATION**; never present them as evidence.
- Do not publish graphic violence, explicit sexual content, illegal instructions or glorification of harm.
- Respect privacy, dignity and consent.
- Show corrections and update timestamps visibly; retain the reference trail.
- Require final editor approval before publication.
- Attribute official statements; do not treat them as independently proven facts.

## Current scope

The repository contains the initial responsive dashboard and a story-intake prototype. Live news feeds, user authentication, publishing integrations and deployment are not yet connected.
